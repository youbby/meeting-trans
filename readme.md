# Standalone Meeting Transcriber · 로컬 회의 기록

Windows PC에서 마이크와 PC 출력의 음성을 텍스트로 변환하고, 발화자와 입력 출처를 표시하는 데스크톱 프로그램입니다. 음성 인식·발화자 분석·에코 제거·문서 생성은 로컬에서 실행합니다.

버전: 0.1.0 / 수정일: 2026-10-12

## 현재 상태

실행 코드, 한국어 UI, 로컬 모델, MD·PDF 내보내기를 구현했습니다. 자동 테스트와 샘플 음성을 이용한 통합 검증을 수행했습니다. 현재 버전은 **현장 시험용**입니다. 실제 회의실의 다인 대화 정확도, 장시간 지연, 다른 PC에서의 호환성은 추가 확인이 필요합니다. 검증 범위와 측정 결과는 [검증 기록](docs/VALIDATION.md)을 확인해 주세요.

소스 저장소는 [youbby/meeting-trans](https://github.com/youbby/meeting-trans)입니다. 실행 패키지의 GitHub Release는 아직 게시하지 않았습니다. 최초 요구사항은 [설계 원문](docs/requirements.md)에 보존했으며, 실제 구현 상태는 이 문서가 기준입니다.

## 실행하기

준비된 패키지에서는 `MeetingTranscriber.exe`를 실행합니다. 소스 폴더 기준 위치는 다음과 같습니다.

```text
dist/MeetingTranscriber/
  MeetingTranscriber.exe
  _internal/                 실행에 필요한 Python·DLL·폰트
  models/                    로컬 음성 인식·발화자 모델
  readme.md
  enable_firewall.ps1         이 실행 파일만 차단하는 선택적 방화벽 설정
```

다른 PC로 옮길 때는 **폴더 전체**를 복사합니다. EXE만 복사하면 실행되지 않습니다. 별도 Python 설치 없이 실행하도록 구성했으며, Windows 11 x64·CPU 처리를 기준으로 개발했습니다. 모델을 포함하므로 충분한 디스크 여유 공간이 필요합니다.

소스에서 실행하려면 이 PC에서는 `run.bat`를 실행하면 됩니다. 새 개발 환경의 준비 절차는 아래에 있습니다.

## 사용 순서

1. 마이크와 PC 출력 장치를 선택합니다. PC 출력은 회의 앱이나 동영상이 실제로 재생되는 장치와 같아야 합니다.
2. **마이크**, **PC 출력** 체크박스로 전사할 입력을 각각 선택합니다. 기록 중에도 켜고 끌 수 있습니다.
3. 스피커를 사용하면 **스피커 재수음 제외(AEC)**를 켭니다. 기본값은 켜짐입니다.
4. 회의 제목을 입력하고 **기록 시작**을 누릅니다. 모델을 읽은 뒤 수집을 시작합니다.
5. 텍스트가 먼저 표시되고, 분석이 끝나면 발화자가 갱신됩니다. 오른쪽 발화자를 더블클릭하여 이름을 바꿀 수 있습니다.
6. 잘못 인식한 내용이나 발화자 배정은 전사 행을 더블클릭하여 수정합니다.
7. **종료 및 저장**을 누르면 남은 구간을 처리하고 `session.json`, Markdown, PDF를 로컬에 저장합니다.

기록 중 **MD 저장 + PDF 생성**은 중간본을 만듭니다. 종료 후 이름이나 내용을 수정했다면 같은 버튼으로 문서를 다시 생성합니다. **세션 열기**에서 기존 `session.json`을 열어 편집·재출력할 수 있습니다. 열린 세션에 녹음을 이어 붙이는 기능은 없으며, 기록 시작은 새 세션을 만듭니다.

기본 저장 위치는 `%LOCALAPPDATA%\StandaloneMeetingTranscriber\sessions`입니다. **설정 / 모델 경로**에서 모델·저장 폴더, 에코 지연, 발화자 유사도 기준을 바꿀 수 있습니다.

## 구현한 기능

| 기능 | 동작 |
| --- | --- |
| 마이크 입력 | 같은 공간의 여러 참석자를 MIC 입력에서 분석 |
| PC 출력 입력 | WASAPI loopback으로 회의 앱·동영상·같은 장치의 출력 음성을 직접 수집 |
| 독립 수집 선택 | 마이크만, PC 출력만, 둘 다, 일시정지 지원 |
| 발화자 구분 | 각 입력에서 음성 구간과 특징을 분석하여 세션 발화자 ID 부여 |
| 입력 출처 유지 | 발화자·전사·JSON·MD·PDF에 마이크(MIC) / PC 출력(SYSTEM) 보존 |
| 이름 변경 | 같은 발화자의 과거·이후 발언에 반영; 재출력 시 문서에도 반영 |
| 수동 수정 | 전사 내용과 같은 입력 출처 내 발화자 배정 변경 |
| 스피커 재수음 억제 | PC 출력 참조와 WebRTC AEC로 처리한 MIC만 전사 |
| 실시간 화면 | 음성 구간별 결과 갱신, 미확정 라벨, 입력 레벨, 대기 구간·지연 표시 |
| 문서 저장 | UTF-8 Markdown → 로컬 PDF 변환, 한국어 글꼴 포함 |
| 로컬 보존 | JSON 자동 저장, 선택 시 처리된 오디오 보존; 기본 오디오 저장 꺼짐 |

`정리`는 시간순 정렬·화자 이름·문서 서식 정리를 뜻합니다. 자동 회의 요약이나 결정 사항 추출은 포함하지 않습니다.

## 마이크의 스피커 재수음 처리

```text
PC 출력 ─┬─> 출력 전사 켜짐일 때 SYSTEM 전사·발화자 분석
         └─> AEC 참조 ─┐
마이크 ───────────────> AEC ─> MIC 전사·발화자 분석
                                  ↓
                   이름·출처·시간 → 화면 / JSON / MD → PDF
```

PC 출력 전사를 꺼도 마이크 AEC를 켰다면 **에코 제거용 출력 참조 수집 중**이라고 표시합니다. 이 참조는 메모리에서만 사용하고 SYSTEM 전사·발화자 생성·오디오 저장에는 전달하지 않습니다. 마이크를 끄면 마이크 수집도 중단하며, 두 입력을 끄거나 일시정지하면 오디오 수집을 중단합니다.

출력 참조가 맞지 않거나 누락되면 해당 MIC 구간을 원본으로 우회 처리하지 않고 처리 공백을 기록합니다. 장치 연결이 끊어지면 오류를 표시하고 세션을 종료합니다. 장치를 다시 연결하고 새로고침한 뒤 새 세션을 시작해야 합니다. 자동 장치 재연결은 아직 지원하지 않습니다.

AEC는 에코를 억제하는 기능이며 완전 제거를 보장하지 않습니다. 클리핑·큰 음량·잔향·장치 지연에 영향을 받습니다. 다른 기기에서 재생되는 소리는 선택한 PC 출력 참조에 없으므로 같은 방식으로 제거할 수 없습니다. 양쪽이 동시에 말할 때 마이크 전체를 음소거하거나 같은 문장이라는 이유로 MIC 전사문을 삭제하지 않습니다.

회의 앱의 음소거와 이 프로그램의 마이크 수집은 별개입니다.

## 발화자 구분과 실시간 처리의 범위

- MIC도 SYSTEM도 여러 사람을 분석합니다. MIC를 한 사람이나 `나`로 고정하지 않습니다.
- 번호는 세션 전체에서 중복 없이 부여합니다. 이름을 바꿔도 내부 ID와 출처는 유지합니다.
- 같은 사람이어도 MIC와 SYSTEM 사이에서는 자동으로 합치지 않습니다. 입력 경로를 보존하기 위한 동작입니다.
- 짧거나 모호한 목소리는 미확정으로 남을 수 있습니다. 겹친 발언은 표시하지만 섞인 목소리를 완전히 분리하지는 않습니다.
- 발화자 모델은 중국어 학습 기반 3D-Speaker ERes2Net입니다. 한국어 회의실의 정확도를 수치로 검증하지 않았으며, 사람 수를 잘못 추정하거나 같은 사람에게 새 번호를 붙일 수 있습니다.
- 이름과 특징의 연결은 현재 세션 안에서만 사용합니다. 음성 특징은 메모리에만 두고 세션 파일에 저장하지 않습니다.
- 음성 구간은 최대 약 6초 단위이며, 잠깐의 침묵 뒤에는 더 빨리 처리합니다. 완성된 구간에 대한 계산 시간이 추가되므로 지연은 PC 성능·입력 수·대화 양에 따라 달라집니다. 지속적인 동시 발언에서는 대기열이 쌓일 수 있습니다.
- 대기열 한도를 넘으면 누락된 구간을 세션 이벤트에 기록합니다. 텍스트 생성과 발화자 분석은 UI·수집과 분리된 작업에서 수행합니다.

기본 음성 인식 모델은 지연을 줄이기 위한 Whisper **base 다국어**입니다. 이 PC의 두 입력 샘플 검증에서 20.5초 분량을 약 13.5초에 처리했습니다. 실제 발언 후 화면 표시 지연을 뜻하는 수치는 아닙니다. 더 큰 `small` 모델은 같은 검증에서 약 35초가 걸렸으나 한국어 샘플의 일부 단어를 더 정확히 인식했습니다. 성능에 여유가 있다면 별도의 모델 폴더를 준비해 설정에서 선택할 수 있습니다.

```powershell
# 선택 사항: 별도 온라인 준비 도구로 큰 모델 준비 후 UI에서 models-quality 선택
.\.venv\Scripts\python.exe scripts\prepare_models.py --whisper small --destination models-quality
```

## 외부 전송과 네트워크 차단 범위

**차단 대상은 이 전사 프로그램입니다. Windows 전체, 브라우저, Teams·Zoom 등 다른 앱의 인터넷 연결은 변경하지 않습니다.** 회의 앱이 통화를 위해 상대방에게 전송하는 음성은 그 앱의 동작입니다.

실행 프로그램은 외부 전사 API·자동 다운로드·업데이트 확인·원격 오류 보고를 사용하지 않습니다. 모델은 로컬 경로로만 읽으며 없으면 안내하고 중단합니다. 모델 라이브러리의 오프라인 모드·텔레메트리 비활성화를 설정하고, Python 프로세스의 DNS·연결·전송 호출도 차단합니다. 로컬 모델로 전사·발화자 분석·PDF 출력을 실행하는 검증에서 이 차단기에 기록된 네트워크 시도는 0건이었습니다.

Python 차단기는 OS 방화벽과 다릅니다. 네이티브 DLL까지 OS 수준에서 강제하려면 패키지의 `enable_firewall.ps1`을 관리자 PowerShell에서 실행할 수 있습니다.

```powershell
# 패키지 폴더에서 실행: 이 위치의 MeetingTranscriber.exe에만 송신 차단 적용
.\enable_firewall.ps1
```

방화벽 규칙을 자동 설치하지 않으며, 현재 검증에서는 이 규칙을 적용하지 않았습니다. EXE를 다른 경로로 이동했다면 새 경로에서 다시 설정해야 합니다. 일반 `python.exe` 전체를 차단하는 규칙은 만들지 않습니다. 프로그램이 별도 네트워크 작업용 하위 프로세스를 실행하지 않으며, 최초 설치·모델 준비 도구는 실행 프로그램과 분리되어 있습니다.

최초 준비에는 패키지·모델 다운로드를 위한 인터넷이 필요합니다. `scripts/setup.ps1`, `scripts/prepare_models.py`는 이 준비 단계의 **온라인 도구**이며 실행 앱에서 호출하지 않습니다. 준비가 끝난 폴더를 다른 PC로 복사하면 모델 다운로드 없이 사용할 수 있습니다.

UNC·네트워크 드라이브 저장은 거부합니다. 로컬의 OneDrive 등 동기화 폴더는 다른 프로그램이 전송할 수 있으므로 저장 위치는 동기화되지 않는 로컬 폴더를 선택해야 합니다.

## 저장 파일

세션별 하위 폴더를 만들며, 파일명에는 시각·제목·세션 ID가 포함됩니다.

```text
sessions/20261012_143000_a1b2c3d4/
  session.json
  2026-10-12_143000_회의기록_a1b2c3d4.md
  2026-10-12_143000_회의기록_a1b2c3d4.pdf
  mic.wav       오디오 보존 선택 시, AEC 켜짐이면 처리 후 음성
  system.wav    오디오 보존과 PC 출력 전사를 함께 선택한 경우에만
```

MD와 PDF에는 회의 정보, 발화자 이름·출처, 시간별 전사, 미확정·겹침 상태, 처리 공백 이벤트가 들어갑니다. 저장된 MD를 읽어 PDF를 만들며, 원격 이미지·폰트를 읽지 않습니다. PDF 실패 시 MD는 유지되고 저장 버튼으로 재시도할 수 있습니다. 동일 세션은 재생성하고 다른 세션의 파일은 덮어쓰지 않습니다.

JSON은 처리 구간마다 저장하고, UI의 편집 내용은 약 2초마다 자동 저장합니다. 오디오 보존을 선택하지 않으면 앱에서 WAV를 만들지 않습니다. 임시 오디오와 음성 특징은 처리 중 메모리에서 사용합니다.

## 개발·검증·빌드

Python 3.12 x64를 권장합니다. `uv` 또는 Python launcher와 Python 3.12가 있어야 새 가상환경을 만들 수 있습니다.

```powershell
# 최초 1회 온라인 준비
.\scripts\setup.ps1

# 오프라인 앱 실행
.\run.bat

# 개발용 도구 설치, 테스트
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest -q

# 실제 로컬 모델·AEC 로딩과 장치 탐색 (녹음하지 않음)
.\.venv\Scripts\python.exe main.py --self-check --report output\self-check.json

# 화면 예시 (녹음하지 않음)
.\.venv\Scripts\python.exe main.py --demo

# 폴더형 실행 패키지 제작
.\scripts\build.ps1
```

`models/manifest.json`은 사용 모델의 파일 크기·SHA-256·출처를 보존합니다. 실행 시 주요 파일의 존재와 크기를 검사하며, SHA-256은 준비·배포 점검용입니다. 앱의 실행 중 자동 모델 갱신은 없습니다.

| 구성 | 사용 기술 |
| --- | --- |
| 오디오 | PyAudioWPatch WASAPI + soxr 스트리밍 리샘플링 |
| 에코 억제·음성 검출 | pywebrtc-audio의 로컬 WebRTC 처리 |
| 음성 인식 | faster-whisper + Whisper base 다국어(기본), CPU INT8 |
| 발화자 분석 | sherpa-onnx + pyannote segmentation 3.0 ONNX + 3D-Speaker ERes2Net |
| UI | Tkinter/ttk |
